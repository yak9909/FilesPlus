# SMB Implementation Plan (Phase 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Browse and open files on SMB shares from the patched Files app: saved connections, a ModKit-owned browser opened from "Other storage", a DocumentsProvider for SAF/preview, thumbnails, and FileOps/MoveQueue integration.

**Architecture:** smbj bundled into the (single-dex) extension; a small `smb/` package (`SmbClientFactory`, `SmbSessionPool`, `SmbVfs`, `SmbConnectionStore`, `SmbDocumentsProvider`, `SmbBrowserActivity`); manifest entries added by the existing manifest resource patch; one bytecode patch hooks the "Other storage" tap.

**Tech Stack:** Morphe patcher (Kotlin patches, resourcePatch for manifest, smali hook), Java extension (no Android resources; programmatic UI), smbj 0.15.0, Android Keystore (AES-GCM).

**Spec:** `docs/DESIGN.md` §5.3, §5.3.1, §5.3.2, §4.1 and the "調査結果と決定" block in §5.3. Worker rules: `docs/WORKER_BRIEF.md`. Style references: `patches/.../misc/ModKitIntegrationPatch.kt` (manifest patch, settings activity), `extensions/.../settings/ModSettingsActivity.java`, `extensions/.../move/{FolderBrowser,DestinationSheet}.java` (programmatic UI), `DiagLog`.

## Global Constraints

- Keep the original app's look: no new resources; programmatic views; reuse the dialog/palette helpers.
- Fingerprints use strings/shapes, never obfuscated names. Every hook Throwable-safe with `DiagLog`, falling back to original behavior.
- The extension is ONE dex: total methods < 65,536. Report the method count after adding smbj. If it overflows, enable R8 per DESIGN §5.3 (dontobfuscate; keep `app.filesplus.extension.**` and `org.bouncycastle.jcajce.provider.**`).
- smbj: SMB2/3 only, NTLM only (no Kerberos/GSS), use smbj's default `BCSecurityProvider` (changed after the Task 1 review; never register "BC" by name). Add new licenses to `NOTICE`. Task 1 is done (merged into dev, `835eb5d`); the extension dex has 52,785 methods, so keep Tasks 2-7 small and plan R8 before adding anything big.
- Authority: manifest = `<package attr> + ".smb.documents"`; code = `context.getPackageName() + ".smb.documents"`. No full-authority string constants.
- No password in plain text anywhere (Task 2: Keystore AES-GCM). Never log passwords.
- JDK 21 for builds; one Gradle run at a time. Do not commit. Worktree `E:/Projects/ModdedFiles-wt/smb` (branch `w/smb`).

## Review Focus

1. Dex method count / R8 fallback; no class clashes with the app's own classes.
2. Android crypto: bundled BC vs the platform "BC"; NTLM works (MD4/HMAC-MD5 via the bundled provider).
3. Network off the main thread; timeouts; connection reuse and clean close.
4. Credentials: encrypted at rest, not logged, not in intents or diagnostics text.
5. A missing share/host/wrong password gives a clear, short error message (not a stack trace) in the diagnostics UI.
