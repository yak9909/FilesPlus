# SMB Implementation Plan (Phase 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Browse and open files on SMB shares from the patched Files app: saved connections, a ModKit-owned browser opened from "Other storage", a DocumentsProvider for SAF/preview, thumbnails, and FileOps/MoveQueue integration.

**Architecture:** smbj bundled into the (single-dex) extension; a small `smb/` package (`SmbClientFactory`, `SmbSessionPool`, `SmbVfs`, `SmbConnectionStore`, `SmbDocumentsProvider`, `SmbBrowserActivity`); manifest entries added by the existing manifest resource patch; one bytecode patch hooks the "Other storage" tap.

**Tech Stack:** Morphe patcher (Kotlin patches, resourcePatch for manifest, smali hook), Java extension (no Android resources; programmatic UI), smbj 0.15.0, Android Keystore (AES-GCM).

**Spec:** `docs/DESIGN.md` §5.3, §5.3.1, §5.3.2, §4.1 and the "調査結果と決定" block in §5.3. Worker rules: `docs/WORKER_BRIEF.md`. Style references: `patches/.../misc/ModKitIntegrationPatch.kt` (manifest patch, settings activity), `extensions/.../settings/ModSettingsActivity.java`, `extensions/.../move/{FolderBrowser,DestinationSheet}.java` (programmatic UI), `DiagLog`.

## Global Constraints

- Keep the original app's look: no new resources; programmatic views; reuse the dialog/palette helpers.
- Fingerprints use strings/shapes, never obfuscated names. Every hook Throwable-safe with `DiagLog`, falling back to original behavior.
- The extension is ONE dex: total methods < 65,536. Report the method count after adding smbj. If it overflows, enable R8 per DESIGN §5.3 (dontobfuscate; keep `app.filesplus.extension.**` and `org.bouncycastle.jcajce.provider.**`).
- smbj: SMB2/3 only, NTLM only (no Kerberos/GSS), use smbj's default `BCSecurityProvider` (changed after the Task 1 review; never register "BC" by name). Add new licenses to `NOTICE`. Task 1 is done (merged into dev, `835eb5d`); the extension dex has 52,785 methods, so keep Tasks 2-7 small and plan R8 before adding anything big.
- Authority: manifest = `<package attr> + ".smb.documents"`; code = `context.getPackageName() + ".smb.documents"`. No full-authority string constants.
- No password in plain text anywhere (Task 2: Keystore AES-GCM). Never log passwords.
- JDK 21 for builds; one Gradle run at a time. Do not commit. Worktree `E:/Projects/ModdedFiles-wt/smb` (branch `w/smb`).

## Review Focus

1. Dex method count / R8 fallback; no class clashes with the app's own classes.
2. Android crypto: bundled BC vs the platform "BC"; NTLM works (MD4/HMAC-MD5 via the bundled provider).
3. Network off the main thread; timeouts; connection reuse and clean close.
4. Credentials: encrypted at rest, not logged, not in intents or diagnostics text.
5. A missing share/host/wrong password gives a clear, short error message (not a stack trace) in the diagnostics UI.

### Task 2: `SmbVfs` core and `SmbConnectionStore` (Keystore AES-GCM) + connection settings UI

**Files:** create `extensions/.../smb/SmbConnection.java` (value class), `SmbConnectionStore.java`, `SmbSecretBox.java`, `SmbSessionPool.java`, `SmbVfs.java`; modify `ModSettingsActivity.java` (new "SMB" section: list, add, edit, delete) and `ModSettings`-style storage as needed. Worktree `E:/Projects/ModdedFiles-wt/smb` (merge `dev` into `w/smb` first: `git -C ../ModdedFiles-wt/smb merge dev`).

**Interfaces:**
- `SmbConnection`: immutable `id` (random UUID string), `displayName`, `host`, `port` (445), `share` (required), `startPath`, `user`, `domain`, `openWhere` (`START` or `LAST`), `lastPath`; the password is NOT a field of this class.
- `SmbSecretBox`: `static String encrypt(String plain)` / `static String decrypt(String blob)` using an Android Keystore AES-256-GCM key (alias `filesplus_smb`, created on first use, `setUserAuthenticationRequired(false)`), random 12-byte IV prepended, Base64 output; returns `null` from `decrypt` on any failure (never throws, never logs the plaintext).
- `SmbConnectionStore`: `static List<SmbConnection> all()`, `static SmbConnection get(String id)`, `static void save(SmbConnection c, String passwordOrNullToKeep)`, `static void delete(String id)`, `static String password(String id)`, `static void setLastPath(String id, String path)`. Storage: a private SharedPreferences file `filesplus_smb` (JSON array of connections without passwords; passwords as `pw.<id>` → `SmbSecretBox` blob). Never log passwords or blobs.
- `SmbSessionPool`: `static DiskShare acquire(SmbConnection c)` returning a connected, authenticated `DiskShare` kept per connection id and reused; reconnect transparently if the connection is closed/broken (one retry); idle close after 60 s via a single daemon-less `ScheduledExecutorService` (shut down not needed; thread name `filesplus-smb-pool`); `static void release(String id)` (marks last use), `static void closeAll()`. All blocking calls are for background threads only (assert/throw `IllegalStateException` if called on the main Looper thread).
- `SmbVfs` (per connection): `List<SmbEntry> list(String path)` (name, isDir, size, mtimeMillis; hide `.`/`..`; cache the listing in memory for 30 s keyed by path, dropped after any mutation), `SmbEntry stat(String path)`, `InputStream openRead(String path, long offset)` plus `long size(String path)` (seekable reads via smbj `File.getInputStream()` + skip, or offset reads through `File.read(byte[], long, int, int)`), `void mkdirs(String path)`, `void delete(String path, boolean recursive)`, `boolean rename(String from, String to)`. Paths use `/` separators internally and are normalized (no `..`, collapse repeated separators, convert `\` to `/`); a path escape attempt throws `IllegalArgumentException`.

### Task 3: manifest patch + minimal `SmbDocumentsProvider`

**Files:** modify `patches/.../misc/ModKitIntegrationPatch.kt` (`modKitManifestPatch`); create `extensions/.../smb/SmbDocumentsProvider.java`, `SmbDocId.java` (doc id encode/decode). Worktree: merge `dev` into `w/smb` first.

**Interfaces / rules:**
- Manifest: add `<provider android:name="app.filesplus.extension.smb.SmbDocumentsProvider" android:authorities="<package attr>.smb.documents" android:exported="true" android:grantUriPermissions="true" android:permission="android.permission.MANAGE_DOCUMENTS">` with `<intent-filter><action android:name="android.content.action.DOCUMENTS_PROVIDER"/></intent-filter>`. Read the package from the manifest `package` attribute AFTER the Change package name patch ran (declare `dependsOn` as the existing manifest patch does); never hard-code the authority. Skip adding if a provider with that name already exists (idempotent).
- Doc id: `<connectionId>:<path>`; root doc id `<connectionId>:`; one root per saved connection (`COLUMN_ROOT_ID` = connection id, title = display name or host/share, flags `FLAG_SUPPORTS_IS_CHILD`, `FLAG_LOCAL_ONLY` NOT set). `queryRoots` refreshes via `notifyChange` when the connection list changes (call from `SmbConnectionStore.save/delete`).
- `queryChildDocuments`/`queryDocument` use `SmbVfs.list/stat` (background-thread rule: DocumentsProvider calls are already on binder threads, which is allowed; reject only the main Looper). `openDocument` read mode only: `StorageManager.openProxyFileDescriptor(MODE_READ_ONLY, ProxyFileDescriptorCallback, handler)` with `onRead` -> `SmbVfs` offset read, `onGetSize`, `onRelease`; handler thread named `filesplus-smb-proxy`. Write/delete/rename/create are NOT supported yet (no flags).
- Errors: map `SmbException` to `FileNotFoundException`/`IOException` with the short message from `SmbErrors`; never throw other unchecked types from the provider; Throwable-safe with `DiagLog`.
- The provider calls `ModKit.init(getContext())` on `onCreate` (it can run before any activity).
- Note from review: Samba with `follow symlinks` hides links; recursive delete is not exposed here.
